# Nectar Publisher Agents 🐝

Nectar Publisher integrates **AI Agents** as part of its "Human-in-the-Loop" workflow to automate and enhance the documentation of tabular datasets. These agents assist researchers in creating high-quality, machine-actionable metadata following DDI (Data Documentation Initiative) standards.

## Overview

Agents in Nectar Publisher are AI-driven components designed to handle the tedious aspects of data annotation. By leveraging Large Language Models (LLMs), these agents can analyze variable names, labels, and data samples to suggest meaningful definitions, detect units of measurement, and identify appropriate data types.

## Key Capabilities

### 1. Automatic Metadata Enrichment
When importing datasets via external services (e.g., Dataverse or OpenCPU), Nectar Publisher can fetch pre-processed AI results. The system specifically looks for `ollama_remote` data or other LLM-generated outputs to populate:
- **Variable Definitions**: Providing semantic descriptions for cryptic column names.
- **Unit Detection**: Identifying if a variable represents energy (eV), time (seconds), etc.
- **Properties Extraction**: Guessing roles (Identifier, Measure, Attribute) and scales.

### 2. Intelligent Type Guessing
The application includes logic to "guess" the intended data type of a column by analyzing its unique values against various regular expressions (Integer, Decimal, DateTime, Boolean, etc.). This acts as a primary "Agentic" feature to reduce manual configuration.

### 3. Human-in-the-Loop Integration
Agents are not meant to replace the researcher. Nectar Publisher's UI allows users to:
- Review AI-suggested definitions in the **Variables** tab.
- Override or refine any metadata before final export.
- Use AI results as a base for manual "coding" of variables (e.g., mapping numeric values to labels).

## Interoperability Standard

To ensure seamless integration with external AI Agents and data inventories, Nectar Publisher supports a standardized JSON structure for **CDIF Variable Inventories**. This structure allows external services to prepare metadata that Nectar Publisher can ingest and map directly to its internal DDI models.

### Standard JSON Schema
External agents should produce an array of objects following this schema:

```json
{
  "variable_type": "Quantitative | Qualitative | Temporal",
  "variable_name": "Unique identifier or name of the variable",
  "value": "Description: The specific data value or sample observed",
  "unit_scale": "Measurement unit (e.g., Count, People/Year) or standard (ISO 8601)",
  "variable_definition": "Semantic description or impact analysis"
}
```

Example usage can be found in [tests/drought_cdif_inventory.json](file:///Users/vyacheslavtykhonov/projects/nectar-publisher/tests/drought_cdif_inventory.json).
